# 固定收益分析工具

选择、计算或审核必需的分析图表时阅读本文件。应选择最能直接检验两个核心论点之一的工具。

## 固定息债券价格与 DV01

设面值为 `F`，年票面利率为 `c`，到期收益率为 `y`，每年付息次数为 `m`，剩余期数为 `N = 剩余年限 × m`：

`P(y) = Σ[t=1..N] (F × c / m) / (1 + y/m)^t + F / (1 + y/m)^N`

使用上下各 1 个基点的中心重估计算 DV01：

`DV01 = [P(y - 0.0001) - P(y + 0.0001)] / 2`

该数值近似表示收益率下降 1 个基点时的价格上涨额；在对称局部近似下，也等于收益率上升 1 个基点时价格下跌额的绝对值。说明结果是每 100 面值还是已按整个头寸放大。已知现金流时间时，中心重估通常比直接引用修正久期更适合复现。

必须披露：结算与现金流约定、付息频率、到期日或剩余期数、收益率约定、净价或全价、面值或头寸规模、平行移动假设，以及嵌入期权的处理。对于可赎回或可回售债券，不得在未说明重大局限的情况下直接套用普通到期一次还本模型。

## 持有收益与骑乘收益

短期持有分析应拆分各组成部分，不要含糊地统称为“持有收益”：

`票息应计 ≈ 面值 × 年票面利率 × 持有期年数`

`融资成本 ≈ 融资金额 × 年融资利率 × 持有期年数`

`净持有收益 ≈ 票息应计 + 再投资收入 - 融资成本`

`骑乘收益 ≈ -修正久期 × 在收益率曲线不变假设下因期限缩短产生的预期收益率变化`

说明是否计入票息应计、融资、再投资、骑乘收益、违约损失、交易成本和盯市变化。“收益率曲线不变”是一项假设，不是预测。

## 利差比较

`利差 = 目标资产收益率 - 基准收益率`

使用同一观察日期，并精确定义基准。尽量匹配期限或久期。区分国债利差、互换利差、信用利差、零波动利差和期权调整利差；这些概念不能互换。比较对象应具有可比性，并披露流动性、税收、期权、评级、行业和指数成分差异。

历史分位数本身不能证明均值回归或估值便宜。

## 融资现金流

按日期列出所有现金流入和流出：购买结算、票息、本金、回购或其他融资、保证金/抵押品及期末出售价值。计息天数与复利约定应和来源一致。说明流动性及再融资假设。

## DV01 对冲

若目标头寸 DV01 为 `D_t`，每单位对冲工具的 DV01 为 `D_h`：

`对冲单位数 = -D_t / D_h`

符号应抵消目标头寸的局部平行利率风险。说明合约或面值单位，并讨论残余的曲线、基差、凸性、流动性和融资风险。DV01 中性并不意味着非平行移动下的损益中性。

## 输入来源状态

在每项输入旁使用以下一种标签：

- `报告原值`：周报直接给出的数值；
- `推导值`：由报告原值透明计算得到；
- `外部来源`：取自其他来源，并注明链接/提供者和观察日期；
- `示意值`：原始输入缺失时，仅用于演示计算方法的假设数值。

不得暗中混用不同状态。若报告输入缺失导致无法复现，应把计算称为“应用”或“示意”，不得称为“复现”。
