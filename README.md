# Bond Weekly Interpreter

债券周报解读 Skill：将来源可识别、日期明确的债券或固定收益周报，转化为可复核的英文分析简报、固定收益计算、来源附录和带图演示材料。

## 适用场景

适用于分析：

- 券商固定收益周报；
- 微信公众号发布的债券市场周报；
- 有明确发布日期和覆盖周期的利率、信用或其他固定收益研究报告。

输入可以是 PDF、图片、粘贴文字或网页链接。

## 主要工作

Skill 会依次完成：

1. 核验报告来源、作者、标题、发布日期、覆盖周期和数据定义；
2. 建立来源台账，记录事实、图表和计算输入的位置；
3. 重建市场背景，并区分市场事实与报告作者的解释；
4. 选择恰好两个核心论点，分析其机制、假设、证据和脆弱点；
5. 审核价格、收益率、利差、资金流和估值指标的定义、单位、频率与日期；
6. 根据论点选择并复现或应用固定收益工具，例如 DV01、持有收益、骑乘收益、利差比较、融资现金流或对冲；
7. 提供独立评估、竞争性解释、局限以及会加强或削弱论点的后续证据；
8. 对最终材料进行来源、公式、单位、日期、输入状态和版式核验。

## 默认输出

除非用户缩小范围，Skill 会准备：

- 两页英文分析简报；
- 计算与图表支撑文件，优先使用 `.xlsx` 或 `.csv`；
- 精简来源附录；
- 支持 15–20 分钟汇报的英文 `.pptx`、预览 `.pdf` 和英文讲稿或演讲者备注。

演示文稿应同时包含一张来源图表和一张原创分析图表，并清楚区分“作者观点”和“我们的评估”。

## 数据与计算规则

每项输入都必须标记为以下状态之一：

- `报告原值`：周报直接给出的数值；
- `推导值`：由报告原值透明计算得到；
- `外部来源`：来自其他明确标注的来源；
- `示意值`：原始输入缺失时用于演示方法的假设数值。

输入缺失时，不得声称已经精确复现报告。计算必须披露公式、单位、日期、来源、假设、中间结果和局限。

## 本地参考材料的边界

仓库中附带的案例和演示材料只能用于参考分析结构、表达方式、版式、图表组织和解析测试。

它们不得被用作：

- 本次周报的来源；
- 本次分析的事实、数值、引文或图表；
- 计算输入或证据；
- 用户网页或链接失效时的替代材料。

如果用户提供的网页无法访问，应保留来源缺口，并请用户提供 PDF、图片、文字或新的可访问链接。即使本地案例与用户周报的机构、主题或日期相同或相似，也不得回退使用本地周报。

## 计算脚本

`scripts/bond_math.py` 用于普通固定息、到期一次还本债券的价格和 DV01 计算。它不负责读取 PDF、网页或图片，也不会自动从周报中提取数据；周报中的输入必须先由分析流程核验和标注。

## 使用方式

在支持目录化 Skill 的 Agent 中，将本目录作为一个 Skill 安装或加载，并提供待分析的债券周报。目标 Agent 需要能够读取相应文件类型，并在需要时运行 Python 脚本和生成图表、文档或演示文件。

## 许可与第三方材料

本仓库的许可证只适用于作者拥有或有权授权的内容。第三方周报、演示文稿、图片、图表和其他材料不因放入本仓库或选择某个许可证而自动获得再发布授权。公开或分享前，请确认所有附带材料的版权和使用许可。
